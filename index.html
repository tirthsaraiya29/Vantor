Capabilities

Multi‑Layered Detection Engine

Vantor combines machine learning, static analysis, heuristic evaluation, and cryptographic hashing into a unified threat assessment pipeline.

XGBoost ML Inference

Native C API integration extracts PE characteristics — section entropy, image size, entry points, executable section flags — and passes feature vectors to trained models for real‑time classification scoring.

feature_vector = {
  section_count: 7,
  entropy_avg: 6.42,
  writable_exec: true,
  image_size: 0x1A000,
  checksum_valid: true
}
model.predict(features) → 0.94

Heuristic Analysis

Evaluates digital signatures, double‑extension patterns, file size anomalies, and execution from commonly abused directories to produce a normalized risk score.

Cryptographic Quarantine

Isolates threats with AES‑256‑GCM authenticated encryption, random IVs, integrity tags, and Windows DPAPI‑protected keys. SQLite‑backed metadata enables safe restoration.

Real‑Time ETW Monitoring

Event Tracing for Windows captures kernel process events, filesystem activity, registry persistence changes, and startup directory modifications in real‑time.

PE Feature Extraction

Deep structural analysis of Windows executables: section characteristics, entry points, checksum verification, and entropy measurements across all PE sections.

AntiTamper Integrity

SHA‑512 baseline measurements, directory‑change monitoring via ReadDirectoryChangesW, backup copies, and automatic restoration when critical files are modified.

Ransomware Burst Detection

Behavioral analysis tracking process‑level file‑write rates, directory distribution, and file entropy to detect and terminate ransomware‑like activity patterns.
